# database

アプリで使用・監査する研究用データです。

- catalog.json: 初期馬台帳
- lineage_codes.json: A/B/C大系統コード
- nicks_verified_2026-10-05.json: 確認済みニックス表
- verified_pair_theories.json: 個別配合理論の確認記録
- verified_routes.json: 確認済みロードマップ
- verified_pedigrees_v62.json: 収録済み祖先データ
- kotta_reference_groups.json: 凝った配合の参考グループ
- data_quality_v70.json: 現版の判定範囲と既知制約
- ancestor_import_template.csv: 祖先データ追加用テンプレート

未登録は「非成立」や「クロスなし」を意味しません。
