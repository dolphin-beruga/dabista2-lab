# ダビスタ2 配合研究ラボ v7.1

ダービースタリオン2向けの配合研究・逆算支援ツールです。
任意の繁殖牝馬を起点に、1〜5代の配合候補を探索し、成立条件・根拠率・推定種付け料などを比較できます。

## v7.1 の主な改善

- 237種牡馬 / 327繁殖牝馬を対象にした馬名クイック検索
- 逆算結果の再ソート
  - おすすめ順
  - 確認済み項目数順
  - 根拠率順
  - 推定種付け料順
- 最低確認項目数フィルター
- 最接近ルート除外フィルター
- 各ロードマップに推定総種付け料を表示
- 各候補に「上位の理由」を表示
- 逆算条件のブラウザ自動保存 / 復元
- 画面内の旧バージョン表記を v7.1 に統一
- スマホ表示のレイアウト改善

## ローカルで使う

Windowsでは `START.cmd` を実行してください。

または `index.html` を直接開いて利用できます。一部ブラウザ機能はローカルファイル制約の影響を受ける場合があります。

## GitHub Pagesで公開する

このリポジトリには `.github/workflows/pages.yml` を同梱しています。

1. このフォルダの内容をGitHubリポジトリへpush
2. GitHubの **Settings → Pages** を開く
3. **Source** を `GitHub Actions` に設定
4. `main` ブランチへpushするとPages公開Workflowが実行されます

静的HTMLアプリなので、ビルド処理は不要です。

## 主なファイル

- `index.html` — アプリ本体

## データ・判定上の注意

- 探索スコアは「最強馬が生まれる確率」ではなく候補比較用の指標です。
- 未確認の凝った配合・ニックス・クロス / 因子は、非成立や0点として捏造せず未確認として扱います。
- 全564頭の完全5代血統、およびSwitch 2版の凝った配合一般式は継続検証項目です。
- 未来牝馬では登録祖先情報から血統を合成するため、祖先DB不足部分は要確認です。
